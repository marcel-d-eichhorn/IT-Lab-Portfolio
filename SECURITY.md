# Security Policy

Dieses Repository ist ein Lern- und Portfolio-Repository.

## Umgang mit sensiblen Daten

- Keine Passwörter, API-Keys, Tokens oder privaten Schlüssel committen.
- Interne Hostnamen, IP-Adressen, Benutzernamen und Kundendaten vor Veröffentlichung anonymisieren.
- Screenshots vor dem Commit auf sensible Informationen prüfen.
- Beispielkonfigurationen ausschließlich mit Dummy- oder Lab-Daten veröffentlichen.

## Gefundene sensible Daten

Falls versehentlich sensible Informationen veröffentlicht wurden, sollten sie nicht nur aus dem aktuellen Commit entfernt, sondern zusätzlich aus der Git-Historie bereinigt und die betroffenen Zugangsdaten rotiert werden.
