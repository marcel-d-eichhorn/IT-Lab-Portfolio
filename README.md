# IT Lab Portfolio

Praxisorientierte Labs und Projekte rund um **Systemintegration, IT-Security, Linux, Networking, Cloud und Automation**.

Dieses Repository dokumentiert nicht nur fertige Ergebnisse, sondern auch technische Entscheidungen, Tests, Troubleshooting und Lessons Learned.

## Projekte

### Security
- [Repo Security Checker](security/repo-security-checker/) – Python-basierter Secret-Scanner mit Git Pre-Commit Hooks, YAML-Regeln und JSON-Ausgabe.

### Cloud
- [Azure Basics](cloud/azure-basics/) – Resource Groups, Storage Accounts, virtuelle Maschinen, Benutzer/Rollen und Kostenkontrolle in Microsoft Azure.

## Portfolio-Richtung

Geplante bzw. laufende Dokumentationen:
- Wazuh SIEM & Detection Engineering
- Debian / Docker Homelab
- Sophos Firewall & Netzwerkarchitektur
- Docker Swarm / High Availability
- Dell PowerEdge / RAID / Serveradministration
- Sysadmin Troubleshooting Case Studies
- PowerShell- und Python-Automation

## Grundsätze

- Keine produktiven Zugangsdaten oder Secrets im Repository
- Interne Umgebungen und Kundendaten werden anonymisiert
- Screenshots werden vor Veröffentlichung auf sensible Informationen geprüft
- Konfigurationen werden als nachvollziehbare, reproduzierbare Beispiele dokumentiert
